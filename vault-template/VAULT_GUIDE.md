# Iphox Memory vault

This vault is the human-readable source of truth for Iphox Memory.

Agents should read project/rule/decision/handoff notes relevant to the current task and avoid
bulk-loading the vault. New durable memories should first be treated as candidates and promoted
only when the memory policy says the information is worth preserving.

Current truth excludes notes marked `superseded` or `archived` unless historical context was
explicitly requested.
